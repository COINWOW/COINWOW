# Bitcoin Core release notes (upstream history)

The files in this directory are the **original, unmodified release notes of
Bitcoin Core** (versions 0.3.12 through 29.0). COINWOW Core is a fork of
Bitcoin Core and inherits the code described here, so these notes are kept
for provenance and to explain the history of inherited features.

They are **not** COINWOW release notes. Version numbers, dates, contributors,
links and security advisories in these files refer to Bitcoin Core and the
Bitcoin network, not to COINWOW.

COINWOW's own release notes start with COINWOW Core v1.0.0 and live in
[`doc/coinwow/`](../coinwow/).
